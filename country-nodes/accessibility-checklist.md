# Accessibility Checklist

Target: WCAG 2.2 AA.

- [ ] Captions for audio and video
- [ ] Transcripts where practical
- [ ] Clear AI disclosure
- [ ] Keyboard accessibility
- [ ] Screen-reader compatibility
- [ ] Reduced-motion mode
- [ ] Photosensitivity controls
- [ ] Plain-language options
- [ ] Physical access review
- [ ] Quiet space and sensory accommodations
- [ ] Offline fallback
- [ ] Multilingual support
- [ ] Display brightness, distance, and duration guidance
- [ ] Accessibility issues logged and resolved
