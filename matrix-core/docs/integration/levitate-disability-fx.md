# Integration guide: `levitate-disability-fx`

Consume the pinned `v0.1.0` access-preferences, consent, membership, acceptance, check and audit contracts from this repository; do not maintain a divergent schema copy. Accommodation choices are not diagnoses. Share only participant-selected fields with explicit purpose, recipient, expiry and revocation.

Keep participant stop and withdrawal independent of financial approval and Arena. Validate the current accepted plan/equipment versions and do not treat a hash as proof that evidence or a reviewer is truthful. No changes to the downstream repository are included.
